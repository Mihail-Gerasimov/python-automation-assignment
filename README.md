# Как проверить решение

Нужен **Python 3.10 или новее**. Окружение `.venv` и requirements-файлы общие для проекта.
Результаты проверок — в [Решение.md](./Решение.md). Работа с ИИ — в [Работа_с_ИИ.md](./Работа_с_ИИ.md).
Исходное ТЗ — [docs/Задание.html](./docs/Задание.html).

| Папка | Что внутри и что проверять |
| --- | --- |
| [zadanie_1](./zadanie_1/) | Обработчик реестра, два файла тестов, исходный `Реестр.xlsx` и готовый `Результат.xlsx` |
| [zadanie_2](./zadanie_2/Задание_2.md) | Текстовый ответ по ежедневному отчёту; программу запускать не нужно |
| [zadanie_3](./zadanie_3/) | Исправленный `plan.py` и `test_plan.py` |

## Windows

Дважды нажмите [run_windows.cmd](./run_windows.cmd). Он подготовит окружение,
установит зависимости, выполнит задания 1 и 3 и запустит 31 тест.
Окно останется открытым с результатом или сообщением об ошибке.

Для ручного запуска откройте PowerShell **в корне проекта**:

```powershell
py -3 -m venv --clear .venv
.\.venv\Scripts\python.exe -m pip install --require-hashes -r requirements.txt
.\.venv\Scripts\python.exe zadanie_1/process_registry.py
.\.venv\Scripts\python.exe zadanie_3/plan.py
.\.venv\Scripts\python.exe -m unittest discover -s zadanie_1 -p "test_*.py" -v
.\.venv\Scripts\python.exe -m unittest discover -s zadanie_3 -p "test_*.py" -v
```

## macOS / Linux

Откройте терминал **в корне проекта** и выполните:

```bash
python3 -m venv --clear .venv
.venv/bin/python -m pip install --require-hashes -r requirements.txt
.venv/bin/python zadanie_1/process_registry.py
.venv/bin/python zadanie_3/plan.py
.venv/bin/python -m unittest discover -s zadanie_1 -p "test_*.py" -v
.venv/bin/python -m unittest discover -s zadanie_3 -p "test_*.py" -v
```

На обеих платформах первые две команды нужны для подготовки среды.
Если она уже готова, начинайте с запуска задания. Для первой установки зависимостей нужен интернет.
Окружение из репозитория относится к машине разработки. На новом компьютере первая команда
пересоздаёт `.venv` под установленный Python; код и файлы заданий остаются на месте.

## Что получится

- **Задание 1:** [zadanie_1/Результат.xlsx](./zadanie_1/Результат.xlsx) — 8 договоров,
  сумма 28471.40; добавлены «Статус», «Карточка», «Пояснение».
- **Задание 3:** JSON в терминале — проценты 90.0, 50.0, null; общий процент 56.0.
- **Тесты:** два успешных запуска — `Ran 27 tests`, затем `Ran 4 tests`, оба с `OK`.

Обработчик по умолчанию читает реестр и сохраняет результат **в папке zadanie_1**,
даже при запуске из другой папки. Исходник не меняется; прежний результат заменяется.
Если результат заблокирован в Excel, закройте его перед запуском.
Свою книгу и место сохранения можно задать через `--input` и `--output`;
явные относительные пути считаются от текущей папки терминала.

Для команд из ТЗ сначала перейдите в `zadanie_3`: `cd zadanie_3`.
Затем выполните `python plan.py` и `python -m unittest -v test_plan.py`.
В Windows вместо `python` можно использовать `py -3`, в macOS/Linux — `python3`.
Заданию 3 дополнительные библиотеки не нужны.
