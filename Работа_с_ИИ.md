# Работа с ИИ

Работал через **Codex CLI**. Использовал сетап проекта: правила в [AGENTS.md](./AGENTS.md),
планы по фазам и скиллы для разбора задачи, написания тестов и упрощения кода.
В частности, `tdd` — для проверки поведения, `code-simplifier` — для чистоты кода.
Оркестрация помогала распределять отдельные проверки между агентами.
Сначала разбирал условия и составлял план, затем переходил к реализации и проверке результата.

Решения выбирал сам: искал информацию, сравнивал варианты и смотрел, что подходит под ТЗ.
С ИИ дополнительно разбирал нюансы и возможные ошибки. Выбрал Python, openpyxl и unittest:
для работы с Excel достаточно одной библиотеки, а средства тестирования уже есть в Python.
Отдельно разобрали, как сохранить ведущие нули и копейки, обработать повторный запуск,
исправленные файлы и одновременную работу нескольких сотрудников.

ИИ поручал подготовку кода и тестов, разбор ошибок и проверку решения по требованиям.
Передал [ТЗ](./docs/Задание.html), [Реестр.xlsx](./zadanie_1/Реестр.xlsx),
[plan.py](./zadanie_3/plan.py) и [test_plan.py](./zadanie_3/test_plan.py).
Сразу обозначил правила: сохранять все договоры и исходные данные, считать общий процент
по суммам, при нулевом плане возвращать `None`. Один из запросов в краткой передаче:
«Начни работу по первой задаче по согласованной фазе и покажи команды запуска по ТЗ».

После реализации прошли 27 тестов реестра и 4 теста расчёта.
Например, общий процент должен был получиться `(90 + 450 + 20) / 1000 × 100 = 56.0`.
Программа вернула **56.0** — значит, факт отдела с нулевым планом тоже учтён.
В изменённой копии реестра ожидались 9 строк и сумма **10024.43**; получился тот же результат,
без дублей. Подробности проверок оставил в [Решение.md](./Решение.md).

Код после ИИ пришлось доработать. В обработчике реестра нашлась ошибка:
если не удавалось заменить результат и удалить временный файл, возникал необработанный
`PermissionError`. Этот случай воспроизвели тестом и исправили обработку ошибки.
Теперь программа сообщает причину сбоя и сохраняет прежний результат.
Для расчёта плана тоже добавили проверки чисел: они выявили ошибки исходного примера,
а после исправления прошли.
