# Стек

| Задача | Решение и причина |
| --- | --- |
| Язык | Python 3.10+ по ТЗ; проверено на 3.12.6 |
| Excel | openpyxl 3.1.5: сохраняет текстовые номера, числовые суммы и формат ячеек |
| Запуск | Стандартные argparse и pathlib: параметры файлов и переносимые пути |
| Тесты | unittest и tempfile: проверка расчётов и настоящих временных XLSX |
| Окружение | venv и pip: стандартная установка без отдельного менеджера пакетов |
| Проверка кода | Ruff 0.17.4, настройки в ruff.toml |

Runtime-зависимости и хеши — в [requirements.txt](../requirements.txt);
инструменты разработки — в [requirements-dev.txt](../requirements-dev.txt).
et-xmlfile 2.0.0 — зависимость openpyxl. `.python-version` хранит локальную версию.

## Модули

- `zadanie_1/registry_rules.py` — статусы, карточки и пояснения.
- `zadanie_1/registry_excel.py` — чтение, проверка и сохранение книги.
- `zadanie_1/process_registry.py` — параметры запуска и сообщения об ошибках.
- `zadanie_3/plan.py` — расчёт процентов; использует только стандартную библиотеку.

Запись Excel выполняется во временный файл рядом с результатом, затем через
`os.replace`. Ошибка записи не должна повреждать прежний результат.
Правила обработки не дублируются между модулями.

Node.js и `package.json` обслуживают оркестрацию агентов; Python-решению они не нужны.
Команды для проверяющего — в [README](../README.md).
