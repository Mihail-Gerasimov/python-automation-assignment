Задание по аналитике автоматизации и ИИ

Выполните три задания для отдела аналитики: подготовьте реестр, предложите порядок ежедневного выпуска отчёта и исправьте ошибку в решении ИИ. Нас интересует, как вы превращаете задачу в повторяемый процесс и проверяете результат.

Формат: самостоятельная работа с последующей отправкой результата. Ориентир — до 2 часов суммарно. Срок отправки результата сообщает организатор. Если не успели, сдайте готовую часть и обозначьте остаток.

ИИ разрешён и нужен: используйте привычный ИИ-инструмент хотя бы в одной практической задаче. Вы отвечаете за принятые решения и проверку. Запись экрана и полный чат не нужны.

1 Обработать реестр

Сотрудник вручную переносит результаты проверки людей в список договоров. Сделайте повторяемую обработку файла Реестр.xlsx, которая создаёт отдельный Результат.xlsx.

В исходном файле два листа. Договоры — 8 строк, каждая обозначает отдельный договор. Ответы — готовые результаты условного сервиса. Связь между листами — поле Код человека. Один человек может иметь несколько договоров.

Что указано на листе ОтветыСтатус в результате
Успешно и одна карточкаНайдено
Успешно и карточек нетНе найдено
Успешно и несколько карточекНужна проверка
Ошибка или строки с таким кодом нетОшибка проверки

Карточки перечислены через точку с запятой; пустая ячейка означает отсутствие карточек. По каждому коду на листе Ответы не более одной строки. Это готовый результат сопоставления: искать людей по имени и обращаться к внешнему сервису не нужно.

Требования к результату

  • Сохраните каждую строку листа Договоры, исходный порядок и все исходные поля. Два договора одного человека остаются двумя строками.
  • Добавьте столбцы Статус, Карточка, Пояснение. Карточку заполняйте только при статусе «Найдено». В пояснении коротко укажите причину результата.
  • Номер договора остаётся текстом с ведущими нулями; сумма — числом с двумя знаками после запятой. Исходный файл не изменяйте.
  • Обработка должна работать при другом количестве строк той же структуры. Подставлять готовые ответы вручную нельзя.

Можно использовать скрипт, макрос, Power Query или другой воспроизводимый способ. Передайте исходник или запрос и короткую инструкцию повторного запуска. Интерфейс, установка приложения, SQL и база данных не требуются.

Автоматизация процесса и проверка ИИ

2 Организовать ежедневный выпуск отчёта

Три отдела каждый день кладут Excel в общую папку. В каждом файле есть дата отчёта, код отдела, номер договора и сумма. К 10:00 аналитик должен подготовить единый отчёт за текущую дату.

Сегодня к 09:45 пришли два файла из трёх. В 09:55 один отдел прислал исправленный файл за ту же дату. Вчера аналитик добавил к отдельным договорам ручные комментарии — они должны сохраниться. Один договор может встречаться в разных отделах; внутри одного отдела и даты номер договора уникален.

Задание: предложите конкретный порядок автоматизации этого процесса — от появления файлов до готового отчёта. Реализовывать программу для этого блока не нужно. Достаточно одной страницы текста или схемы.

  1. Что запускает обработку и как она определяет нужную дату, отдел и версию файла?
  2. Что происходит в 10:00, если третьего файла нет? Как получатель узнает, что отчёт неполный?
  3. Что делать с исправленным файлом и повторным запуском, чтобы не удвоить суммы?
  4. Где хранить ручные комментарии и как связать их с договорами, чтобы они пережили новый расчёт?
  5. Какие проверки нужны перед выдачей отчёта? Где потребуется решение человека?

Выберите рабочие правила и явно запишите допущения. Важнее последовательность и объяснение решений, чем названия технологий.

3 Проверить и исправить решение ИИ

В файле plan.py — учебный пример кода, который мог написать ИИ. Он считает выполнение плана по отделам и общий процент. Автор решения утверждает: «Всё готово, проверка проходит».

ОтделПланФакт
А10090
Б900450
В020

Правила: процент отдела = факт / план × 100. При нулевом плане процент не определён: верните None (в JSON — null), а не 0%. Общий процент = сумма фактов / сумма планов × 100; факт отдела с нулевым планом тоже входит в сумму. Если общий план равен нулю, общий процент также не определён. Округление — один знак после запятой.

Разберитесь, почему текущей проверке нельзя доверять. Исправьте расчёт с помощью ИИ или самостоятельно, запустите его и добавьте минимум две автоматические проверки: общего процента и нулевого плана. Допустим другой язык с теми же правилами. Входные данные корректны и неотрицательны; обработка ошибочных типов не требуется.

Состав результата и пояснения

Что отправить

  1. По реестру: Результат.xlsx, исходник обработки или запрос, инструкция запуска. Для Power Query подойдёт книга с запросом и указанием, как заменить входной файл и обновить результат.
  2. По ежедневному отчёту: выбранная последовательность действий и ответы на пять вопросов из задания 2, до одной страницы.
  3. По расчёту плана: исправленный код, добавленные проверки и результат их запуска.
  4. Короткое объяснение работы с ИИ: до одной страницы по вопросам ниже. Всё пояснение можно собрать в один документ «Решение».

Что объяснить про ИИ

Опишите именно выполненную работу, чтобы её можно было обсудить после сдачи:

  • Какой инструмент использовали и какую часть работы ему поручили?
  • Какие данные и правила вы ему передали? Приведите один фактически использованный запрос или его точную краткую передачу.
  • Какое решение вы приняли сами и почему?
  • Что проверили после ответа ИИ? Укажите конкретный пример: ожидание, полученный результат и вывод.
  • Пришлось ли что-то исправлять после ИИ? Если да — что именно и чем подтвердили исправление. Если нет — так и напишите, придумывать ошибку не нужно.

Как проверить себя перед отправкой

  • Реестр содержит столько же строк, сколько исходный лист Договоры. В нём сохранились оба договора одного человека, копейки и ведущие нули.
  • Ошибка сервиса отличается от успешного ответа без карточек. Несколько карточек не превращаются в одну подтверждённую.
  • Вы можете повторить обработку на изменённой копии файла. Опишите хотя бы одну такую проверку и её результат.
  • В расчёте плана есть проверки чисел, а не только наличия строк в ответе.
  • Из инструкции понятно, что открыть или запустить и где появится результат.

Запуск примера plan.py

Для приложенного примера нужен Python 3.10 или новее. Дополнительные библиотеки ему не нужны. Откройте терминал в папке задания и выполните:

python plan.py
python -m unittest -v test_plan.py

В Windows вместо python можно использовать py -3. Если выбрали другой язык, приложите свои команды запуска.

Все исходные данные вымышлены. Задание не требует доступа к рабочим системам, внешним API и реальной базе данных. Для последующего обсуждения достаточно присланных файлов и ваших объяснений; наблюдение за работой в реальном времени не предполагается.
