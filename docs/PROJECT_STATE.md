# Состояние проекта

Все три задания выполнены. Ответы и результаты — в [Решение.md](../Решение.md),
команды — в [README.md](../README.md).

## Файлы

- `docs/Задание.html` — неизменённое исходное ТЗ.

- [zadanie_2/Задание_2.md](../zadanie_2/Задание_2.md) — ответ по ежедневному отчёту.
- `zadanie_3/` — plan.py и test_plan.py.

- `requirements*.txt`, `.venv` и `ruff.toml` — общая среда и настройки проверки кода.
- `AGENTS.md`, `.agents/skills/`, `.codex/config.toml`, `package.json` — инструменты агента.
- `project-phases/` и [карта фаз](./PHASES_OVERVIEW.md) — выполненные этапы работы.

## Окружение

Проверено: Python 3.12.6, pip 24.2, openpyxl 3.1.5, et-xmlfile 2.0.0, Ruff 0.17.4.
Версии зависимостей закреплены в requirements-файлах. В состав публикации включены
локальное окружение и кэши. На другом компьютере `.venv` пересоздаётся по README.

Чистая установка ранее проверена на macOS. После переноса оба скрипта и 31 тест
проверены из новой структуры; результат по умолчанию создаётся в zadanie_1.
Windows-файл просмотрен по коду; в Windows и Linux запуск не выполнялся.
Синтаксис Python-файлов проверен для версии 3.10; runtime-прогон — только на 3.12.6.
