# Фаза 2. Обработка реестра

**Статус:** выполнена. Результат и изменённая копия — в
[разделе 1 решения](../Решение.md#1-обработка-реестра).

## Контракт

Код, два файла тестов, исходник и результат находятся в `zadanie_1`.

Вход — листы `Договоры` и `Ответы` из Реестр.xlsx; связь — «Код человека».
Выход — отдельная книга Результат.xlsx: все договоры и исходные поля в прежнем порядке,
затем «Статус», «Карточка», «Пояснение». Правила статусов заданы в [ТЗ](../docs/Задание.html).
Номера остаются текстом, суммы — числами с форматом двух знаков. Исходник не изменяется.

## Реализация

Правила находятся в registry_rules.py, работа с XLSX — в registry_excel.py,
команда запуска — в process_registry.py. Ответ рассчитывается один раз на человека.
Новые строки читаются независимо от устаревшего диапазона Excel-таблицы.
По умолчанию вход и результат находятся рядом со скриптом; явные относительные
пути `--input` и `--output` считаются от папки запуска.

| Риск | Решение |
| --- | --- |
| Потеря договоров одного человека | Проход по договорам без группировки и удаления строк |
| Ложное подтверждение карточки | Ошибка сервиса имеет приоритет; несколько карточек требуют проверки |
| Потеря нулей, копеек или текста | Сохранение значений и типов; строки =… и #N/A остаются текстом |
| Неоднозначный вход | Отказ при неизвестных статусах, дублях кодов ответов, неверных заголовках и типах |
| Повреждение исходника или результата | Проверка путей и ссылок; временный файл и замена после успешного сохранения |
| Дубли после повтора | Каждый результат строится заново |

Вход содержит готовые значения. Формулы, ошибки Excel, пустые строки внутри данных
и ключи неверного типа отклоняются с указанием причины. Оформленный пустой хвост
не считается данными. Пробелы вокруг карточек убираются; повтор карточки не подтверждается.
При ошибке записи сохраняется предыдущий результат. Если временный файл нельзя удалить,
программа сообщает его путь. Обработка рассчитана на последовательные запуски.

## Проверки

27 тестов покрывают статусы, реальные XLSX, изменённую копию, повтор, пути,
ошибки данных и сбои записи. Есть проверки нуля и одного договора, скрытых строк,
добавленных столбцов, кириллицы и пробелов в путях. Тесты и Ruff прошли.

Выполнен TDD; после реализации просмотрены весь код и вызовы по code-simplifier.
Книга повторно открыта и проверена визуально. Ограничение PNG-рендера с ведущими нулями
проверено через XML и Quick Look: в самом XLSX номера сохранены.
При переносе изменён тест стандартных путей: он сначала выявил поиск входа
в неверной папке, затем прошёл после привязки путей к скрипту.
Команды — в [README](../README.md); непроверенные платформы указаны в состоянии проекта.
