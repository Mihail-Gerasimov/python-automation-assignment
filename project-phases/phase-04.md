# Фаза 4. Исправление расчёта

**Статус:** выполнена. Код — [plan.py](../zadanie_3/plan.py), тесты — [test_plan.py](../zadanie_3/test_plan.py).
Результат запуска — в [разделе 3 решения](../Решение.md#3-исправление-расчёта-плана).

## Изменения

Общий процент считается по суммам исходных фактов и планов, включая факт отдела
с нулевым планом. При нулевом знаменателе возвращается None, округление — один знак.
Общее правило используется для отделов и итога. Входные данные не изменяются.
Интерфейс функции и команды ТЗ сохранены; дополнительных зависимостей нет.
Код и тесты перенесены в `zadanie_3`; команды ТЗ выполняются из этой папки.

## Проверки

Исходный тест количества отделов сохранён. Добавлены три группы проверок:

- Пример ТЗ: проценты 90.0, 50.0, None; общий 56.0; вход не изменён.
- Нулевой общий план и пустой список: общий процент None.
- Округление и нулевой факт: общий 66.7 для планов 3/3/3 и фактов 1/1/4;
  план 10 и факт 0 дают 0.0.

До исправления новые проверки дали шесть ожидаемых падений, старый тест проходил.
После исправления прошли все четыре метода. Выполнены обе команды ТЗ, Ruff
и просмотр полного кода по code-simplifier. Синтаксис проверен для Python 3.10,
фактический runtime — Python 3.12.6/macOS.
