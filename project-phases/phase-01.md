# Фаза 1. Подготовка окружения

**Статус:** выполнена.

## Задача

Подготовить Python 3.10+, зависимости и команды запуска по [ТЗ](../docs/Задание.html).
Исходные файлы на этапе подготовки не изменять.

## Выполнено

- Создано .venv; зависимости закреплены версиями и хешами.
- Проверены чистая установка runtime, pip check, импорт openpyxl и Ruff.
- Исходный Excel прочитан с сохранением ведущих нулей и числовых сумм.
- Проверены навыки, настройки и запуск исходного примера.

Исходный тест проверял только количество отделов. Его успех подтверждал запуск среды,
но не правильность расчёта; ошибки исправлены в фазе 4.

Команды установки и запуска — в [README](../README.md). Для Windows добавлен
[run_windows.cmd](../run_windows.cmd); фактический Windows-прогон не выполнялся.
